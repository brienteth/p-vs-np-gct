### C. Shifted Partial Derivatives, Padding & ABP Frontiers
1. **Plain PDs (`shift=0`) are blind:** $\dim(\partial^{=k}\mathrm{perm}_n) = \dim(\partial^{=k}\mathrm{det}_n) = \binom{n}{k}^2$ for all tested $(n, k)$.
